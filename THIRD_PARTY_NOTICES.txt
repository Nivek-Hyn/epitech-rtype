Third-party components
======================

The runtime uses Asio for UDP transport and nlohmann/json for server level configuration.
Client-enabled builds also link SFML,
which uses FreeType, HarfBuzz, SheenBidi, Ogg, Vorbis and FLAC in this build.
Copies of their main upstream notice files are installed under notices/.
GoogleTest is used only by tests and is not part of the runtime installation.

Asio: https://think-async.com/Asio/
nlohmann/json: https://github.com/nlohmann/json
SFML: https://www.sfml-dev.org/
FreeType: https://freetype.org/
HarfBuzz: https://harfbuzz.github.io/

Assets and project code
=======================

Every picture of the game (ships, enemies, shots, worlds and interface) is drawn
by the client's own code (client/src/render), from shapes and lines: no image file
is used.

The font is Chakra Petch (assets/fonts/ChakraPetch-SemiBold.ttf), copyright 2018
The Chakra Petch Project Authors, released under the SIL Open Font License 1.1
(assets/fonts/OFL.txt).

The repository currently declares no project-wide source-code license.
The upstream notices do not assign a license to the project's own code or assets.
